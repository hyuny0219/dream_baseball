# 벤치에서 명예의 전당까지 ⚾

나만의 야구선수 키우기 게임. [kickru.com](https://kickru.com/)(벤치에서 발롱까지)의 축구 커리어 시뮬레이션 구조를 야구로 옮긴 브라우저 게임입니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## kickru → 야구 변환표

| 벤치에서 발롱까지 (축구) | 벤치에서 명예의 전당까지 (야구) |
| --- | --- |
| 10개 포지션 (ST~GK) | 10개 포지션: SP, RP, C, 1B, 2B, 3B, SS, LF, CF, RF |
| 시작 후보 오버롤 45, 능력치 6개 | 동일 (야수: 컨택·파워·선구안·주루·수비·송구 / 투수: 구속·제구·변화구·구위·체력·멘탈) |
| 벤치 → 데뷔 → 첫 골 → 우승 → 발롱도르 | 퓨처스 → 데뷔 → 첫 홈런(첫 승) → 우승 → MVP → 명예의 전당 |
| 임대·이적 제안 | 콜업/강등, 트레이드(요청 가능), FA, 포스팅(KBO·NPB·CPBL → MLB), 방출 |
| 리그 (빅5 등) | MLB(+AAA·AA·A), NPB(+2군), KBO(+퓨처스), CPBL(+2군) — 구단은 모두 가상 |
| 발롱도르·개인상 | 리그 MVP, 사이영상/사와무라상 등 최우수 투수상, 신인왕, 골드글러브·골든글러브, 실버슬러거·베스트 나인, 타이틀, 올스타, 시리즈 MVP |
| 월드컵·유로·코파 | WBC, 올림픽(2028), 아시안게임, 프리미어12 (MLB 40인 로스터 출전 제한 반영) |
| — | 한국 국적: 병역(상무 2시즌) 또는 아시안게임 금·올림픽 메달로 병역 특례 |
| 포지션 전환·약발 훈련·집중 훈련 | 포지션 전환(SP↔RP 포함), 스위치 히터, 새 구종, 비시즌 개인 캠프(최대 3회) |
| 늦게 핀 꽃 등 숨은 성장 특성 | 조숙형·보통·대기만성, 부상 체질(토미 존 수술 등) |
| 일일 랭킹·베스트 일레븐 | 기기 내 랭킹(MVP → 최고 OVR → 개인상 → WAR)·포지션별 베스트 나인 |
| 커리어 카드·인생 이야기 | 커리어 카드 이미지 저장, 명예의 전당 득표율, 인생 이야기 타이틀, 실제 통산 기록 비교 |
| 저장 파일 내보내기/가져오기 | 동일 (localStorage + JSON 파일) |

## 구조

- `js/data.js` — 포지션 가중치, 플레이 스타일, 리그·구단·국가·대회 데이터
- `js/engine.js` — DOM 없는 게임 로직 (선수 생성, 시즌·기록·팀 성적·시상, 성장, 계약, 이벤트, 은퇴 평가)
- `js/app.js` — 화면 (해시 라우팅, 허브, 시즌 리포트, 이벤트, 은퇴·랭킹·가이드·설정)
- `test/sim.js` — 엔진만으로 커리어 수백 개를 돌려 밸런스와 오류를 확인

```bash
node test/sim.js 300
```
